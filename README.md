# K4binho Portfolio

Portfólio modular de Matheus Heinrique/K4binho, inspirado no StreamHub e no K4 PLAY.

## Estrutura

- `index.html`: composição da página.
- `styles.css`: sistema visual e responsividade.
- `src/data.js`: conteúdo dos projetos e stack.
- `src/main.js`: renderização e filtros.
- `docs/`: decisões, riscos, requisitos e arquitetura.

## Executar localmente

Abra `index.html` em um navegador ou use qualquer servidor estático local.
