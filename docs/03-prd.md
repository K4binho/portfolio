# PRD — Portfólio modular K4binho

## Objetivo

Apresentar Matheus Heinrique/K4binho como desenvolvedor que cria ferramentas para streaming, mídia, automação, web e servidores.

## Escopo da primeira versão

### Incluído

- Página única responsiva.
- Tema dark tecnológico.
- StreamHub e K4 PLAY como projetos principais.
- Cards filtráveis para os demais projetos.
- Dados centralizados em módulo próprio.
- Links externos configuráveis.
- Deploy estático compatível com GitHub Pages.

### Fora do escopo

- Login ou área privada.
- Banco de dados.
- API dinâmica do GitHub.
- Formulário que envia dados.
- Estatísticas inventadas.

## Requisitos funcionais

- **FR-01:** o visitante deve conseguir navegar entre as seções por links internos.
- **FR-02:** o visitante deve conseguir filtrar projetos por categoria.
- **FR-03:** cada projeto deve exibir nome, descrição, tecnologia e link quando disponível.
- **FR-04:** o site deve apresentar links externos apenas com destinos configurados.
- **FR-05:** o layout deve adaptar-se a telas pequenas.
- **FR-06:** a interface deve respeitar foco de teclado e contraste legível.

## Milestones

1. Fundação modular e conteúdo.
2. Visual e interações.
3. Validação local.
4. Publicação e verificação do site.
